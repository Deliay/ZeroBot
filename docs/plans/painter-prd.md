# 小画家（群聊绘图指令）—— 产品需求文档（PRD）

| 属性 | 值 |
|---|---|
| 需求名称 | 小画家：群聊 AI 绘图指令 |
| 所属插件 | 新增 ZeroBot.Painter |
| 状态 | 待评审 |
| 关联文档 | [技术方案](./painter-tech.md) |

---

## 1. 背景与目标

后台训练服务 `vtuber-training` 已提供图像生成能力：

```
POST {endpoint}/api/training/images/generate
Content-Type: multipart/form-data

text={提示词}
image=@1.jpg   # 可多个，最多 10 张
```

用户希望在群聊中通过指令调用该接口进行绘图（支持以图生图/参考图），同时对每个群、每个群员的每日用量做限制，防止滥用。

**目标：**

- 群管理员可通过指令为本群开启/关闭绘图功能，开启时设定群员每日绘图上限（最大 5 张）。
- 开启后，群员可发送 `/小画家:画:{prompt}` 附带图片（0~10 张）触发绘图，生成结果以图片发回群聊。
- 未开启的群聊使用该指令时完全无响应（静默忽略）。
- 每个群员每天的用量独立计数；**失败的调用同样计入当日用量**。
- 绘图接口耗时可能很长，HTTP 超时需配置为足够大的合理值。

## 2. 名词约定

| 名词 | 说明 |
|---|---|
| endpoint | 后台训练服务地址，默认 `http://z-vtuber-training.vtuber.svc.cluster.local:8080`，支持环境变量与热加载配置 |
| 群员每日上限 | 某群内单个成员一天（UTC+8 自然日）最多可发起的绘图次数，开启时由 `{number}` 指定，取值 1~5 |
| 失败调用 | 绘图接口返回非 2xx、超时、网络异常或返回空结果，均视为失败；失败也消耗一次当日用量 |

## 3. 功能需求

### 3.1 开启绘图功能指令

- **指令格式：** `/小画家:启用:{number}`
- **示例：** `/小画家:启用:3`
- **权限：** 群管理员 / Sudoer / 拥有 `painter.manage` 权限（沿用现有权限模型，与 `/synthesize:limit`、`/动态语音播报` 等管理指令一致）。
- **仅群聊可用。**
- **行为：**
  1. 校验 `{number}` 为整数且 1 ≤ number ≤ 5；不合法（非数字、小于 1、大于 5）→ 回复提示，不写入配置。
  2. 记录「本群 → 每日上限」配置并持久化，回复确认，例如「已开启本群绘图功能，每人每天最多绘制 3 张」。
- 同群重复开启：幂等；使用不同 number 再次开启 = 修改上限（覆盖旧配置），回复确认。当日已消耗的计数不重置。

### 3.2 关闭绘图功能指令

- **指令格式：** `/小画家:禁用`（忽略多余参数）。
- **权限：** 同 3.1。
- **仅群聊可用。**
- **行为：** 移除本群的绘图配置并持久化，回复确认，例如「已关闭本群绘图功能」。
- 未开启过时关闭：幂等，回复确认即可，不报错。
- 关闭后当日计数保留：同日再次开启时，群员已消耗用量仍然有效（避免通过重启开关刷额度）。

### 3.3 绘图指令

- **指令格式：** `/小画家:画:{prompt}`，同一条消息中可附带图片（0~10 张）。
- **示例：**
  - `/小画家:画:一只在樱花树下打盹的猫`（纯文本）
  - 图片 + `/小画家:画:把这张图改成水彩风格`（带参考图）
- **使用条件：**
  - 仅群聊可用；任何群员均可使用。
  - **本群必须已通过 3.1 开启绘图功能**；未开启的群收到该指令时**不做任何响应**（不回复、不贴表情、不计数、不调用接口）。
- **行为：**
  1. 检查该发送人在本群的当日用量：已达上限 → 回复提示（例如「你今天在本群的绘图次数已用完（{number} 张），明天再来吧」），不调用接口。
  2. 未达上限 → **先消耗一次当日用量**，然后给消息贴上「处理中」表情，调用绘图接口。
  3. 提取消息中的图片（最多 10 张，超出部分忽略），连同 `{prompt}` 文本以 `multipart/form-data` 提交：字段 `text` 为提示词，字段 `image` 逐张附加。
  4. 调用成功 → 将返回的图片发送到群聊（回复原消息）；调用失败（非 2xx / 超时 / 异常 / 空结果）→ 回复失败提示。**无论成败，已消耗的用量不回滚。**
  5. 处理结束后移除「处理中」表情。
- `{prompt}` 为空（指令后无文本）→ 视为参数错误，回复提示，不计数、不调用接口。
- `{prompt}` 采用原始文本解析（首个 `:` 之后的全部内容），保留文本中的冒号、连字符等字符，与 `/学` 指令一致。

### 3.4 用量统计

- 计数维度：群（PeerId）+ 发送人（SenderId），互不影响。
- 计数周期：UTC+8（北京时间）自然日，每日 0 点自动重置。
- 计数时机：通过限额检查后、调用接口**之前**即消耗一次；失败调用同样计入（需求明确要求）。
- 计数持久化于配置文件，Bot 重启后当日用量不丢失。

## 4. 非目标（本期不做）

- 按用户个人维度的全局限额（仅群+人维度）。
- 不限额模式（`-1` 不限制）与 0 禁用模式：本需求上限恒为 1~5，不引入 synthesize 的 -1/0 语义。
- 绘图参数（尺寸、步数、风格模型等）调节。
- 绘图历史记录查询、重新生成。
- 私聊场景的绘图。
- 多张图片返回时的合并排版（接口若返回多张则逐张发送）。

## 5. 边界与异常

| 场景 | 行为 |
|---|---|
| 未开启的群使用 `/小画家:画` | 完全静默：不回复、不贴表情、不计数、不调用接口 |
| 未开启的群使用 `/小画家:启用` / `/小画家:禁用` | 管理指令不受开启状态影响，按权限正常处理 |
| 开启时 number 非数字 / <1 / >5 | 回复参数错误提示，不写入配置 |
| 群员当日已达上限 | 回复额度用完提示，不调用接口 |
| 绘图接口超时 / 非 2xx / 网络异常 / 空响应 | 回复失败提示；用量已消耗，不返还；记录错误日志 |
| 附带图片超过 10 张 | 仅取前 10 张，其余忽略 |
| 消息不含图片 | 正常处理，仅提交 `text` 字段 |
| prompt 为空 | 回复参数错误提示，不计数 |
| 群关闭后同日重新开启 | 当日已消耗计数仍然有效 |
| Bot 重启 | 开启状态、上限与当日计数均从配置恢复 |
| 开启状态修改/关闭与正在进行的绘图并发 | 以发起时状态为准，进行中的调用完成并回发结果 |

## 6. 配置与运维

- 新增热加载配置 `painter-config.json`：endpoint（默认取环境变量 `Z_VTUBER_TRAINING_ENDPOINT`，与 synthesize 同一服务）、HTTP 超时、群配置表、当日用量表。
- 不修改任何线上既有配置文件；群的开启/上限通过群内指令维护。
- 绘图接口超时可能很长（分钟级），超时时间独立配置，默认 10 分钟，且不复用其他插件的 HttpClient 超时设置。

## 7. 验收标准

1. 群内发送 `/小画家:启用:3`（有权限）→ 回复开启成功；`painter-config.json` 出现该群配置。
2. 群内发送 `/小画家:启用:6` 或 `/小画家:启用:abc` → 回复参数错误，配置未变。
3. 未开启的群发送 `/小画家:画:test` → 无任何响应（无回复、无表情）。
4. 已开启的群发送 `/小画家:画:一只猫` → 贴上处理中表情，稍后收到生成图片，表情移除。
5. 附 2 张图片发送绘图指令 → 接口收到 2 个 `image` 字段；附 12 张 → 接口只收到 10 个。
6. 上限为 1 的群：首次绘图成功后再次发送 → 回复额度用完；次日（UTC+8 0 点后）恢复可用。
7. 模拟接口返回 500 → 回复失败提示；再次发送时计数已 +1（失败计入用量）。
8. 模拟接口长时间不响应 → 超过配置的超时时间后按失败处理，期间不阻塞其他命令。
9. 无权限用户发送 `/小画家:启用:3` → 不生效（按现有权限模型的既有行为）。
10. `/小画家:禁用` 后 → 绘图指令静默无响应；重复禁用不报错。
11. 关闭后同日重新开启 → 之前已消耗的用量仍然计入。
12. 重启 Bot 后 → 开启状态与当日用量自动恢复。
