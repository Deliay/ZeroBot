# 产品需求：微博订阅推送（ZeroBot.Weibo 插件）

- 日期：2026-09-09
- 状态：待评审
- 关联文档：[weibo-subscription-tech.md](weibo-subscription-tech.md)（技术提案）

## 背景

已有「B站动态推送」（`/B站动态:订阅:{mid}`，见 `src/plugins/ZeroBot.Bilibili/Dynamic/`）验证了「vtuber server 中转 + 群内订阅 + 定时轮询推送」的完整链路。本需求将同一模式复制到微博场景：群内订阅指定微博用户（uid），该用户发布新微博时自动推送到订阅群。

微博数据由同一 vtuber server 中转（`{endpoint}/api/weibo/...`），无需直接对接微博开放平台。

## 目标

1. 群内可通过命令订阅/取消订阅指定微博 uid 的新微博推送。
2. 订阅后，被订阅用户发布新微博时，自动向所有订阅群推送微博内容与配图。
3. 推送行为与 B站动态推送一致：去重、首次订阅不回溯推送、失败持续重试。

## 需求详述

### 1. 订阅命令

- 群聊发送 `/微博:订阅:{uid}`（如 `/微博:订阅:9187735727`）。
- 校验权限（沿用 B站动态推送的权限模式：sudoer / 群管理员 / 功能权限），通过后：
  - 调用 vtuber server 订阅接口 `POST {endpoint}/api/weibo/subscription`，body `{"uid":"{uid}"}`；
  - 本地记录「uid → 当前群」订阅关系并落盘；
  - 回复订阅成功确认。
- 重复订阅同一 uid：幂等，回复已订阅。

### 2. 取消订阅命令

- 群聊发送 `/微博:取消:{uid}`。
- 仅删除本地订阅关系并落盘；**不调用远端取消订阅接口**（服务端订阅保留，由服务端自行管理）。
- 本群是最后一个订阅群时，同时清理该 uid 的推送游标，该 uid 自然停止轮询。
- 回复取消成功确认；本群未订阅时给出提示。

### 3. 新微博推送

- 后台任务每 20 秒轮询一次所有已订阅 uid：`GET {endpoint}/api/weibo/user/{uid}/timeline?page=1&pageSize=1` 取最新一条微博。
- 去重：以 `mblogId` 为游标。本次拉取的 `mblogId` 与本地记录相同则跳过；不同则更新游标并落盘。
- 首次记录（本地游标为空）只落盘游标，**不推送**，避免订阅瞬间轰炸历史微博。
- 拉取失败（网络异常/接口错误/无数据）：记日志并继续下一轮，持续重试。
- 推送目标：该 uid 的所有订阅群；经当前在线的全部 Bot 账号发送；**不 at 全体**。
- 同一 uid 的多个订阅群收到同一条微博消息；不同 uid 轮询之间随机间隔 1–3 秒，避免打爆中转服务。

### 4. 推送内容

每条微博渲染为一条群消息，包含：

- 首行：`{博主昵称} 发布了新微博`。
- 正文：微博 `text` 字段经 HTML 清洗（`<br />` 转换行、`<a>` 标签保留可见文本、其余标签剔除、HTML 实体解码）后的纯文本。
- 配图：微博含图片时（`pics[]`），大图 URL 逐张作为图片段跟在文字之后。
- 转发微博：先发转发语，再插入分隔线，递归渲染原微博（`retweeted_status`）；原微博被删除等异常情况给出兜底文案。
- 原文链接：附上 `https://m.weibo.cn/status/{mblogId}` 便于跳转查看。

## 验收标准

| # | 场景 | 预期 |
|---|------|------|
| 1 | 群内发送 `/微博:订阅:9187735727`（有权限） | 调用远端订阅接口成功，回复确认；该群出现在订阅关系中 |
| 2 | 无权限用户发送订阅命令 | 不响应或提示无权限，不产生任何变更 |
| 3 | 订阅后该 uid 发布新微博 | 20 秒级延迟内推送到所有订阅群，文案+配图完整 |
| 4 | 刚订阅的 uid 已有历史微博 | 不推送历史微博，只推送订阅后新发的 |
| 5 | 同一 uid 被两个群订阅 | 两个群都收到推送，互不干扰 |
| 6 | 群内发送 `/微博:取消:9187735727` | 本群不再收到该 uid 推送；远端取消接口未被调用 |
| 7 | 最后一个订阅群取消 | 该 uid 的游标被清理，轮询停止 |
| 8 | 时间线接口暂时不可用 | 记日志，下一轮继续重试，不影响其他 uid 与其他插件 |
| 9 | 转发微博 / 多图微博 / 含链接与表情的微博 | 均按「推送内容」规则渲染，无原始 HTML 标签泄漏 |

## 非目标

- 不实现远端取消订阅（需求明确：取消只动本地）。
- 不做评论/转发数等互动数据的展示。
- 不支持长微博全文展开（`isLongText` 场景先以截断文本 + 原文链接兜底，后续按需迭代）。
- 不做订阅列表查询命令（可后续补充）。

## 依赖与风险

- 依赖 vtuber server 的 `/api/weibo/*` 接口稳定性；接口不可达时仅影响本功能，须保证异常隔离。
- 端点通过环境变量 `Z_VTUBER_SERVER_ENDPOINT` 注入（与 B站动态推送同一服务、同一环境变量），默认值 `http://vtuber.internal.fffdan.com`。
